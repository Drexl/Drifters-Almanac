Search filters

Plain text matches by name only. To refine your search you can add filter chips.

Building a filter

  1. Start by typing the name of an available filter from the list below. You can press Tab to auto-complete it early.
  2. Type the value, e.g. armor.
  3. Press Tab to complete the filter chip.

You can also type a whole filter at once, e.g. slot:cuirass, then press Tab.

Combining filters

Add as many filters as you like, including repeated filters of the same kind. The All / Any toggle next to the list controls whether every filter must match or any one does.

Removing a filter

Press Backspace in an empty search box to remove the last filter, or click the × on any chip.

    Building a filter

    1. Start by typing the name of an available filter from the list below. You can press Tab to auto-complete it early.
    2. Type the value, e.g. haste.
    3. Press Tab to complete the filter chip.

    You can also type a whole filter at once, e.g. stat:haste, then press Tab.

    Slots

    Choosing a slot in the equipment grid adds its slot: filter, and adding one selects the slot. Choose the selected slot again, or remove the chip, to clear it. There is one slot filter at a time.

    Class

    Loading a saved set, or changing its class, sets the class: filter to that class, so the list shows what it can use. Remove the chip to see everything; the set keeps its class, and a warning beside it says the list can show equipment it can't use.
